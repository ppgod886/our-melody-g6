# 我们的乐章 · Our Melody — GROUP 06

音符环绕五线谱排成一个圆环，每一个音符，都是一位成员。

> 每个人都有自己的声音，但只有合在一起，才是一首完整的歌。

## 体验流程

1. **进入**：整首曲子开始循环流动（建议佩戴耳机 🎧）
2. **点一段谱子**（三段弧线 = 三个小分组）：整曲退后，这段谱子单独响起，组员姓名与职责浮现
3. **点其中一枚音符**：它会响得更大声一点，弹出个人卡片，音符被点亮
4. **全部点亮**：它们同时发声，汇成一段完整的和弦

## 两套外观

右上角 **☾ / ☀** 一键切换，选择会记住：

- **日间（默认）**：象牙白乐器 —— 墨黑与香槟金音符交错、细线乐谱、柔和投影
- **夜间**：黑夜香槟金 —— 发光音符、微光尘埃

## 上传不同小组的名单（无需改代码）

页面右上角 **「⬆ 名单」**：

- **选择文件上传**：支持 CSV / JSON / Excel(.xlsx)
- **下载 CSV 模板**：表格列为 `姓名（必填）、职责、一句话简介、个人特色、声部（1/2/3 或 低/中/高）、音高（可留空自动分配）`
- **导出当前名单**：把正在展示的名单存成 CSV
- **恢复默认名单**：随时回到 15 人默认阵容

规则：

- 人数 3～40 人均可，音符自动重排环上间距；三个声部人数不必相等
- 没填声部的成员会自动轮流分配；音高留空则按声部音区自动配给，音色循环分配
- 名单保存在**本机浏览器**里（localStorage），刷新/重开页面仍在；换设备或点"恢复默认"即回到默认
- 上传后立刻生效：整曲编曲会按新名单的声部人数自动重排，多出来的人会补进空拍，每个人都有声音

## 改默认名单（改代码的方式）

当前默认名单是 **第六组真实的 25 位成员**（2026-10-10 从飞书"成员信息收集"表格抓取，
原始数据存档在 `feishu_all.json`）：

- 姓名 = 昵称（括号里的组内角色挪到职责，如"霍斯(小组长)"→ 霍斯 · 小组长）
- 引言 = "1-2 句人物刻画"；彩蛋 = "代表物 + 为什么是它"
- 声部：表格里没有分组，按 25 人轮转均分（9/8/8）；音高按声部音区自动配给

要调整分组/职责/简介，编辑 `js/members.js` 里的 `MEMBERS_DEFAULT`。

## 技术说明

- 纯静态页面（HTML / CSS / 原生 JS），零依赖、零音频文件；Excel 解析组件按需从 CDN 加载
- 全部音乐由 **Web Audio API** 实时合成：每个人 = 一个音高 + 一种专属音色
- 点亮的人在声部独奏中音量会被永久抬高一截（"这一段里，他更响"）
